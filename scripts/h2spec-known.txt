# h2spec cases that tigerstore's client port fails over TLS or h2c, all of
# them on main before #671 too (#672): the case, a tab, and why it fails.
# scripts/h2spec.sh fails on a case not listed here, and on a listed case
# that passes over both. Each fix of #672 removes its line.
http2/3.5: Sends invalid connection preface	h2c only: a bad preface closes the connection without a GOAWAY
http2/5.1: closed: Sends a DATA frame	DATA on a closed stream is dropped, not a STREAM_CLOSED error
http2/5.1: closed: Sends a DATA frame after sending RST_STREAM frame	DATA after the client's RST_STREAM is dropped, not a STREAM_CLOSED error
http2/5.1: idle: Sends a DATA frame	DATA on an idle stream is dropped, not a PROTOCOL_ERROR
http2/5.1: idle: Sends a RST_STREAM frame	RST_STREAM on an idle stream is ignored, not a PROTOCOL_ERROR
http2/5.1: idle: Sends a WINDOW_UPDATE frame	WINDOW_UPDATE on an idle stream is ignored, not a PROTOCOL_ERROR
http2/5.3.1: Sends HEADERS frame that depends on itself	a HEADERS frame's priority is ignored, so a self-dependency is not refused
http2/5.3.1: Sends PRIORITY frame that depend on itself	PRIORITY frames are ignored, so a self-dependency is not refused
http2/6.4: Sends a RST_STREAM frame on a idle stream	RST_STREAM on an idle stream is ignored, not a PROTOCOL_ERROR
http2/6.9.1: Sends multiple WINDOW_UPDATE frames increasing the flow control window to above 2^31-1 on a stream	only the connection's send window is checked for overflow, not a stream's
http2/8.1.2.1: Sends a HEADERS frame that contains a pseudo-header field as trailers	trailers are not checked for pseudo-header fields
http2/8.1.2.2: Sends a HEADERS frame that contains the TE header field with any value other than "trailers"	te is not checked for the value trailers
http2/8.1.2.2: Sends a HEADERS frame that contains the connection-specific header field	connection-specific header fields are not refused
http2/8.1.2.3: Sends a HEADERS frame that omits ":method" pseudo-header field	a request without :method is not refused as malformed
http2/8.1.2.3: Sends a HEADERS frame that omits ":path" pseudo-header field	a request without :path is served as /
http2/8.1.2.3: Sends a HEADERS frame that omits ":scheme" pseudo-header field	a request without :scheme is not refused as malformed
http2/8.1.2.3: Sends a HEADERS frame with empty ":path" pseudo-header field	an empty :path is served as /
http2/8.1.2.6: Sends a HEADERS frame with the "content-length" header field which does not equal the DATA frame payload length	content-length is not checked against the DATA received
http2/8.1.2.6: Sends a HEADERS frame with the "content-length" header field which does not equal the sum of the multiple DATA frames payload length	content-length is not checked against the DATA received
http2/8.1: Sends a second HEADERS frame without the END_STREAM flag	a second HEADERS frame without END_STREAM on an open stream is not refused
